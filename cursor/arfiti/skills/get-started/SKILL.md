# Get started with Arfiti

Use the connected Arfiti tools to find out where the user is working before doing anything else.

1. Read the current organization and the legal entities the account can access.
2. Tell the user the organization name, each entity's name and country, and its accounting currency.
3. If several entities exist, ask which one the question is about. Do not guess.
4. If no entity exists yet, say that setup is needed and offer to start it. Do not create anything without the user asking.

This check is read-only. Do not create an entity, post a record or change a setting as part of it.

If the connection is not signed in, ask the user to sign in to Arfiti when the connection prompts for it, then continue. The connection guide is at https://arfiti.com/docs/getting-started.

When the user then asks for a change, say what you are about to submit before you submit it. Arfiti validates every write and routes it to the organization's approval workflow, so a submission may complete at once or wait for an approver. Report which of the two happened.
